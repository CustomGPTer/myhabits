No adverts and nothing to unlock in MyHabits

MyHabits has no paid version, no subscription and no adverts, and it cannot go online. Here is how that sits beside three well-known habit trackers on Google Play, going only by what each maker's own listing says.

Download for Android

Habit trackers on Google Play

If you want free and open source

Loop Habit Tracker is free, has no adverts and publishes its source code, which MyHabits does not. If being able to read the code matters most to you, Loop is the one to pick. MyHabits is aimed at someone who wants more around the tick list: journeys, celebrations, rest days and freezes, notes, mood and badges.

Where your habits are kept

MyHabits keeps your habits, history, notes and mood on your phone. It does not ask Android for internet access, so it cannot send them anywhere, and it has no account and no servers. If that matters to you, check each app's privacy policy and its Data safety section on Google Play before you install it.

What MyHabits does not do

  • It is not on Google Play, so it is installed from a downloaded file and updated by installing the new version over the old one.
  • It cannot tell you when a new version is out, because it cannot go online. New versions are listed in the release notes.
  • It does not sync between devices and has no web or iPhone version. Moving to a new phone is done with a backup file.
  • It has no app lock, which HabitNow's listing describes.
  • It has no to-do list or task planner. It tracks habits, not one-off jobs.
  • It has no white noise or focus sounds, which the Habit Tracker - Habit Diary listing describes.
  • Its source code is not published. Loop Habit Tracker's is.
  • Backup files are not encrypted. Anyone who has the file can read your habits, notes and mood, so keep it somewhere you trust.
  • Reminders can arrive a few minutes late when the phone is saving battery.
  • It does not read steps, sleep or anything else from a watch or from Health Connect. You tick habits yourself.
  • The app is in English only.
